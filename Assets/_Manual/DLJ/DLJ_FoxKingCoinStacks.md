# 여우왕 수탈 자원 동전

`DLJ_TestScene` 루트의 `DLJ_FoxKingCoinStacks`에 연결되어 있음.

- 위: `TestCoin`, 왼쪽: `TestCoin (1)`, 오른쪽: `TestCoin (2)`
- 세 견본은 플레이 시작 시 비활성화되며, 편집 모드에서는 위치를 조정할 수 있음.
- 수탈 자원 1당 동전 1개. 견본의 메시, 크기, 머티리얼을 그대로 사용.
- 기본 순서는 **위 → 왼쪽 → 오른쪽 → 위** 반복. 자원 12면 **6 / 3 / 3**.
- 획득 시 0.1초 간격으로 0.24초 낙하/착지 연출. 소비 시 최근 동전부터 제거.
- 여우왕 사망/비활성화 시 비우고, 같은 씬에 새 여우왕이 생성되면 자동 연결.
- 여우왕 전투/투자 로직은 변경하지 않고 `OnStolenResourcesChanged`를 구독.

인스펙터 조절:

| 필드 | 용도 |
| --- | --- |
| Extra Top Coins Per Cycle | 1은 기본 2:1:1. 0이면 위 → 왼쪽 → 오른쪽만 반복 |
| Stack Spacing | 0이면 각 동전 메시의 월드 높이로 자동 계산. 양수면 직접 지정 |
| Spacing Multiplier | 자동 간격 배율. 기본 1.02 |
| Yaw Variation | 각 동전의 수평 회전 변화량 |
| Drop Height / Drop Duration / Coin Interval | 낙하 높이 / 연출 시간 / 생성 간격 |

컨트롤러는 활성 상태의 별도 씬 오브젝트로 유지하고, 인디케이터나 비활성 여우왕 아래로 옮기지 않기.
다른 씬에서 사용하려면 빈 오브젝트에 같은 컴포넌트를 붙이고 여우왕과 세 동전 견본을 연결.

검증 (2026-09-12): 전체 게임 C# 컴파일 통과. 별도 Unity 6000.3.6f1 플레이 모드에서
실제 동전 스크립트·여우왕 자원 코드·TestCoin FBX로 60개 항목 통과.
시작 시 숨김, 순서/2:1:1 배분, 메시/층 높이, 획득·소비·대기 중 소비,
구독 해제/재연결, 사망 시 비우기, 새 보스 연결을 확인.
별도 테스트의 Animal/Health/Phase는 최소 대체 컴포넌트를 사용했으며,
실제 전투 씬의 렌더링 화면은 이 자동 검증에 포함하지 않음.
