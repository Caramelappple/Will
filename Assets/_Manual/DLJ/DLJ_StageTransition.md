# DLJ_GameTestScene 스테이지 전환

`Assets/_Scenes/DLJ/DLJ_GameTestScene.unity`를 열고 Play로 실행.

- 일반: 판 복귀 후 화면 상단에 스테이지 번호를 표시하고 페이드아웃.
- 챕터 변경: 검은 가로 노이즈 → 완전 암전 → 보드 색/배경 교체 → 중앙 지역명 → 페이드아웃.
- 보스: 흰색으로 화면을 덮고 이명을 빠르게 한 글자씩 표시한 뒤, 큰 보스 이름을 세 번의 충격으로 나눠 표시. 이름 타격마다 화면과 카메라가 흔들림.
- 마지막 스테이지 보상까지 끝나면 `여정의 끝` 화면으로 종료. 마지막 판을 재배치하지 않음.

보상 상자의 카드 선택과 새 유언 수령이 끝나면 기존 `LSO_StageIntroDirector`가 다음 진행, 배치, 보드 복귀를 처리. `DLJ_StagePresentation`은 복귀 완료 신호인 `Ready` 이후 연출을 시작.

## 조정

Hierarchy의 `DLJ_StageSequence` → `DLJ_StagePresentation`에서 표시 시간과 Chapter Looks를 조정.

- Chapter: 진행 데이터와 연결할 챕터 에셋.
- Boss Name / Boss Epithet: 보스 이름과 이명.
- Light Tile / Dark Tile: 해당 챕터의 체스판 색. 공유 머티리얼 원본에는 적용하지 않음.
- Environment: 별도 챕터 배경 루트가 있으면 연결. 완전 암전 중 해당 배경만 활성화.
- Source Font: 동적 한글 글꼴 원본. 현재 Song Myung 사용.
- 보스 텍스트 효과 사용: 끄면 이명과 이름을 즉시 표시하고 타자, 타격, 흔들림 효과를 생략.
- Boss Type Interval: 이명을 한 글자씩 표시하는 간격.
- 이명-이름 대기 시간: 이명 타자가 끝난 뒤 이름 첫 타격까지 기다리는 시간.
- Boss Beat Interval / Punch Duration: 보스 이름 세 타격의 간격과 한 번의 강조 시간.
- Boss Shake Duration / Strength / UI Shake: 실제 카메라 흔들림과 흰 화면 위 텍스트 충격 세기.

현재 테스트 디자인은 1챕터의 갈색 보드와 2챕터의 청회색 보드. 별도 배경 모델은 포함하지 않음.

## 테스트 데이터

`Assets/_SO/DLJ/Stage/`에 2챕터, 총 6스테이지와 전용 보상표를 배치.

| 순서 | 내용 |
| --- | --- |
| 1-1, 1-2 | 일반 |
| 1-3 | 황소왕 / 들판의 폭군 |
| 2-1 | 여우왕의 금고 진입 |
| 2-2 | 일반 |
| 2-3 | 여우왕 / 탐욕의 지배자 |

모든 단계에 카드 3개 중 하나를 고르는 보상을 설정. 계약 유언은 최초 수령 시 기존 메모장 흐름을 실행.
유언 메모장은 `DLJ_WillNote` 전용 프리팹 사용. 얇은 클릭 영역과 공백을 포함한 한글 글꼴 적용.
상자의 클릭 영역 높이는 이 씬에서만 1로 줄여 떠 있는 메모장을 가로막지 않도록 설정. 카드 수령 이동은 `motion.deckAnchor`에 연결.
테스트용 적 구성과 보스 이명은 변경 가능. 생존한 아군은 유지하고 다음 판 앞줄에 다시 배치.

## 빠른 확인

플레이 중 `DLJ_StageSequence`의 `DLJ_StagePresentation` 아래 테스트 버튼 사용.

1. 일반 스테이지 (1-2): 번호 표시 확인.
2. 보스 스테이지 (1-3): 흰 화면과 이명/보스 이름 확인.
3. 챕터 변경 (2-1): 앞선 1챕터 테스트 후 사용하면 암전/지역명/색 변경 확인.
4. 현재 스테이지 클리어 → 보상: 실제 뒤집기와 보상 상자 흐름 실행. 상자를 열고 다시 눌러 카드를 꺼낸 다음, 카드 하나와 유언 메모장을 선택하면 자동 복귀.

이동 버튼은 보상을 생략하는 에디터 테스트 기능. 연출/보상 중에는 버튼을 잠금.

## 기존 코드와의 연결

기존 StageDirector 프리팹 인스턴스는 이 씬에서만 비활성화해 중복 로드를 방지. 새 배치는 `DLJ_StageSequence`가 담당.
LSO 진행/보상, LDY 회전/적 생성, KTH 승패 판정을 재사용.

다른 작성자의 스크립트 수정은 `LDY_BoardFlipDirector.PlayReverse()`의 입력 복구 호출 한 줄과 설명 주석뿐. 복귀 후에도 입력이 잠기던 문제를 해결하기 위한 변경.
