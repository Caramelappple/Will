# DLJ 양초 체력 툴팁

- `PlayerHealth.prefab`과 `HealthCandle.prefab` 루트에 `DLJ_CandleHealthTooltip` 연결.
- 자식의 체력 양초에 마우스를 올리면 **양초 묶음 위의 고정 위치**에 총 체력 표시. 최대치는 체력이 남은 양초 수 × 100. 예: 세 초가 살아 있으면 `260/300`, 하나가 꺼지면 `150/200`, 둘이 꺼지면 `50/100`, 전부 꺼지면 `0/0`.
- 여우왕 장부의 `DLJ/Ledger Ink` 셰이더 재사용. 0.65초 동안 글자 획에서 잉크가 번지는 등장 연출, 마우스를 떼면 0.2초 페이드 아웃.
- 숫자와 `/`가 모두 들어 있는 기존 Song Myung SDF 폰트 사용. 툴팁 전용 런타임 머티리얼에 해당 아틀라스를 연결하며 공유 폰트와 장부 머티리얼은 수정하지 않음.
- 피해·회복·세이브 복원 후 표시 중인 총 체력을 매 프레임 확인. 값이 바뀔 때만 번짐 재생. 숨는 도중 재진입하면 기존 진행도를 이어가고 완전히 숨은 뒤 재진입하면 처음부터 재생.
- 초의 실제 축소 비율에 맞춘 Bounds로 판정하므로 별도 Collider나 PhysicsRaycaster 설정 불필요. 완전히 탄 초도 바닥에 작은 판정 영역 유지. 앞을 가리는 물리 Collider와 EventSystem의 UI 위에서는 새로 표시하지 않음.
- 처음 배치된 초의 원래 높이를 기준으로 묶음 위쪽 중앙을 한 번 계산. 마우스를 다른 초로 옮기거나 초가 줄어들어도 위치 유지. 저장된 체력으로 시작해도 원래 높이 기준. 카메라를 향해 회전하며 초의 비균일 스케일을 상속하지 않음. 그룹 비활성화 시 숨기고 제거 시 생성한 텍스트와 머티리얼 정리.
- 일시정지 중에도 등장·퇴장 연출 진행.

## 인스펙터 조절

`PlayerHealth > DLJ_CandleHealthTooltip`에서 설정:

| 항목 | 기본값 | 용도 |
| --- | --- | --- |
| Target Camera | 비움 | Main Camera 자동 탐색 |
| Tooltip Anchor | 비움 | 지정하면 이 Transform을 고정 기준점으로 사용. 비우면 양초 묶음 위쪽 중앙 |
| Font Size | 5 | 글자 크기 |
| Text Color | 옅은 아이보리 | 글자 색상 |
| Height Offset | 0.65 | 고정 기준점에서 월드 위쪽으로 띄울 거리 |
| Spread Duration | 0.65초 | 잉크 번짐 시간 |
| Fade Out Duration | 0.2초 | 사라지는 시간 |

## 검증

- Unity 6000.3.6f1의 실제 게임 참조와 소스 목록으로 전체 런타임 C# 컴파일 통과. 기존 미사용 멤버 경고 2개.
- 검증 프로젝트: `.utmp/DLJ_CandleTooltipQA` (버전 관리 제외). 실제 체력·양초·툴팁 스크립트, Song Myung 폰트, 장부 잉크 셰이더를 사용하며 양초 모델은 단순 메시로 대체.
- 별도 Unity 플레이 모드 검사 40개 통과: 마우스 진입/이탈/재진입, 피해·회복·세이브 복원·새 게임, 초 축소·소멸·호버 대상 변경·재활성 중 고정 위치 유지, 남은 초에 따른 최대 체력 감소, 총합이 같고 최대치만 달라진 경우의 갱신, 일시정지, 가림 판정, 런타임 오브젝트 정리, 공유 머티리얼 보존, 셰이더 컴파일.
- 실제 렌더 이미지 `full.png`에서 양초 위 `300/300` 텍스트 확인. 게임 씬의 URP 조명·후처리와 최종 화면 배치는 별도 플레이 확인 필요.
