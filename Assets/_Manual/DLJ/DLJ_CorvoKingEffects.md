# 까마귀왕 시각 효과

`DLJ_CorvoKingEffects`는 `Assets/_Prefabs/LSO/CorvoKing.prefab`에 직접 연결돼. 그래서 `DLJ_TestScene`에 배치된 인스턴스와 `Corvo King.asset`을 통해 런타임에 생성되는 인스턴스 모두 같은 이펙트를 사용해. 실제 스킬 연동을 위해 `LSO_Predation`에 완료 이벤트, `LSO_MemoryFrenzy`에 충전/소비 이벤트와 읽기 전용 준비 상태 조회를 추가했어. 전투 계산은 그대로야.

- 포식: 0.48초 붉은 표면 섬광과 겹친 실루엣 잔광
- 되먹임: 0.8초 동안 더 진하고 넓게 퍼지는 같은 계열 효과
- 기억 폭주: 붉은 눈을 중심으로 원형의 빛이 부드럽게 번지는 발광. 켜기/끄기 때 함께 페이드

그림 없이 글로만 설명한 사냥감 표식/울음소리는 이번 작업 범위에서 제외했어.

## 직접 재생

1. 씬의 비활성 `CorvoKing`을 켜고 선택해.
2. `DLJ_CorvoKingEffects` 인스펙터 아래의 포식/되먹임/기억 폭주 버튼을 눌러.
3. 편집 모드에서도 Scene 뷰에서 재생할 수 있어. 선택을 해제하면 편집 미리보기는 정리돼.
4. 색상, 지속 시간, 확장량은 해당 필드로 조절해.

눈은 별도 메시가 없어서 메시 로컬 Bounds 안의 두 타원 영역을 사용해. `Eye Center`는 중심, `Eye Separation`은 양쪽 눈 간격, `Eye Radius`는 발광 범위야. Will_Corvo의 로컬 Z가 높이 축이야. 초기 위치는 모델 좌표 기준 추정값이고, 실제 화면에서의 정렬은 확인하지 않았으니 필요하면 조절해.

`Eye Light Spill`의 `Eye Glow Size`는 원형 빛의 지름, `Eye Glow Intensity`는 강도, `Eye Glow Lift`는 모델 표면 밖으로 띄우는 거리야. 빛은 눈 위치를 중심으로 카메라를 향하는 평면에 그리고 가산 합성해. 중심은 밝고 가장자리로 갈수록 부드럽게 흐려지는 원형이며, 블룸 설정 없이도 표시돼. 깊이 검사를 유지하므로 다른 물체를 뚫고 표시하지 않아. `Eye Center`와 `Eye Separation`을 바꾸면 빛의 중심 위치도 같이 바뀌어.

## 전투 연출 연결

`Auto Play Skills`가 켜져 있으면 해당 기물의 실제 특성 인스턴스에 자동으로 연결돼. 기본값은 켜짐이고, 이전 `Observe Inheritance` 설정도 유지돼.

- 포식: `LSO_Predation.OnKill`에서 사냥감 처치 확인과 능력치 적용을 마친 직후 붉은 섬광 재생
- 되먹임: 이미 먹은 종류를 다시 처치하면 특성 유무나 저장 성공 여부와 관계없이 더 강한 되먹임 섬광 하나만 재생
- 기억 폭주: 실제 특성의 `IsReady`가 참이면 원형 눈 발광 유지. 첫 타격에서 폭주가 소비되면 페이드아웃. 공격 횟수 질의 이전에도 준비 상태를 표시하지만 조회로 충전이나 공격 횟수를 바꾸지는 않아

특성이 재생성되거나 되먹임으로 추가돼도 `AbilitiesChanged`를 통해 연결을 갱신해. 비활성화/파괴 때 이벤트를 해제하고 이펙트를 정리해. 다시 활성화하면 현재 폭주 준비 상태만 복구하며 과거 포식 섬광은 재생하지 않아.

플레이 중 인스펙터의 `Runtime Binding`에서 자동 재생, 포식 연결, 기억 폭주 연결, 눈 발광 상태, 메시/머티리얼 준비 여부를 읽을 수 있어. 정상적인 까마귀왕이면 `Auto Play`, `Predation Bound`, `Memory Frenzy Bound`, `Turn Events Bound`, `Mesh / Material Ready`가 모두 켜져 보여야 해.

`LDY_Animal.RegisterAbilities`에서 GameManager가 아직 준비되지 않았을 때도 등록 완료로 처리하던 초기화 순서 문제를 수정했어. 등록할 때 이벤트 관리자를 확보하고, 특성이 추가되거나 해제될 때도 처음 연결한 관리자를 사용해. 기존에는 이 경로에서 사냥감 지정이 턴 알림을 받지 못해 포식 조건을 충족하지 못할 수 있었어.

`Current Prey`는 지정된 사냥감, `Inherited ATK`는 실제 계승량, `Kill Attempts`는 포식 특성이 받은 처치 알림 수, `Devour Events Received`는 이펙트가 받은 포식 완료 알림 수야. 마지막 포식 결과에 사냥감 미지정·다른 기물 처치·동물 데이터 누락 등 실제 중단 이유도 표시돼. 처치 알림은 늘지만 완료 알림이 늘지 않으면 이 중단 이유를 확인하면 돼.

플레이 중 수동 미리보기나 다른 이벤트로 직접 제어할 때는 `Auto Play Skills`를 끄고 아래 API를 호출해.

```csharp
effects.PlayPredation();
effects.PlayFeedback();
effects.SetMemoryFrenzy(true);  // 충전 완료
effects.SetMemoryFrenzy(false); // 공격으로 소비
effects.StopAndReset();
```

현재 전투 코드의 폭주 기준은 2페이즈 진입 이후 총 ATK의 새 6단위 구간이고, 처음 요청한 기획은 계승 ATK 합계라 차이가 있어. 포식량도 기존 코드의 1/3 계산을 그대로 사용해. 이번 연결은 현재 스킬의 실제 판정을 따르며 전투 규칙 자체는 수정하지 않았어.

연출은 원본 메시를 공유하는 임시 렌더러와 `MaterialPropertyBlock`을 사용해. 원본 머티리얼과 콜라이더는 수정하지 않아. 비활성화/파괴 시 임시 오브젝트를 정리해.

후속 디버깅에서 C# 빌드를 확인했어. Unity 플레이 재현과 시각 검증은 아직 수행하지 않았어.

## 2페이즈 날개 등장

### 진입/복귀 카메라 줌

2페이즈 진입 연출 시작에 기본 0.4초 동안 렌즈를 0.88배로 좁혀 살짝 줌인해. 날개 펼침과 지연 방출한 주변 깃털의 수명이 끝날 시점까지 유지한 뒤, 0.15초 추가 대기하고 0.65초 동안 원래 화면으로 줌아웃해. 여기서 복귀는 2페이즈 진입 연출 종료를 뜻하며, 전투 페이즈 자체를 되돌리지는 않아.

`Phase Camera Zoom`에서 `Camera Zoom Enabled`, `Ratio`, `In Duration`, `Out Duration`, `Return Delay`와 진입/복귀 `Curve`를 편집해. Ratio는 1이면 변화 없음, 작을수록 더 가까워져. 곡선의 X/Y는 0~1 시간/진행 비율이고, 줌 설정은 다음 미리보기부터 반영돼.

MainCamera의 Cinemachine Brain과 같은 출력 채널의 CinemachineCamera에 임시 확장을 붙여 렌즈 계산 결과만 조절해. 기존 카메라 이동이나 Brain을 끄지 않고 원본 렌즈 설정을 보존해. Cinemachine 없이 쓰는 MainCamera는 FOV/Orthographic Size를 저장했다가 복구해. 재재생/비활성화/파괴 때 임시 확장을 정리하고 줌을 해제해. 줌 효과는 Game 뷰에서 확인할 수 있어. Unity 실행 테스트는 수행하지 않았어.

### 날개 주변 깃털

`Wing Surrounding Feathers`는 화면 UI와 별개의 월드 연출이야. 날개 펼침 시작 후 `Wing Feather Burst Delay`초가 지나면 기본 48장의 Sprite 깃털을 좌우 날개에서 한 번에 방출해. 첫 약 0.2초에 양옆과 위로 강하게 튀어나온 뒤 빠르게 감속하고, 회전·폭 변화·좌우 흔들림을 보이며 아래로 떨어져 사라져. 보스 이동에 끌려가지 않고 Scene/Game 뷰 모두에서 보여.

- `Wing Feather Sprite`: 주변 깃털 이미지. 비우면 화면용 Feather Sprite를 사용해.
- `Wing Feather Count`, `Lifetime`: 한 번에 터지는 수량과 각 깃털의 기본 생존 시간.
- `Wing Feather Burst Delay`: 날개 펼침 시작부터 깃털을 터뜨리기까지의 시간(초). 기본 0.4, 0이면 즉시, 0.8이면 펼침 시작 0.8초 뒤에 터져. 펼침 시간보다 큰 값을 넣어도 완전히 펼친 날개 표면에서 방출돼. 화면 깃털 종료와 무관하며 재생 중 수정도 반영해. 다시 미리보기를 누르거나 보스를 비활성화하면 이전 방출 대기는 취소돼.
- `Wing Feather Burst Strength`: 처음 튀어나오는 추가 힘(기본 4). 높일수록 강하게 터지며, 0이면 추가 가속 없이 기존 Speed로 퍼져. 순차 방출이나 등장 페이드 없이 시작부터 보여.
- `Wing Feather Size`, `Speed`, `Flutter`: 날개 반폭 기준 크기·퍼지는 속도·흔들리는 거리.
- `Wing Feathers Enabled`: 주변 깃털 사용 여부.
- `Screen Feathers Enabled`: 기존 화면 전환 연출 사용 여부. 끄면 화면을 덮지 않고 날개 펼침과 주변 깃털을 바로 재생해.

주변 깃털은 화면 전환이 끝나도 남은 수명 동안 흩날려. 다시 미리보기를 재생하거나 보스가 비활성화되면 생성한 깃털을 정리해. Unity 실행 테스트는 수행하지 않았어.

`DLJ_CorvoKingPhaseTransition`을 CorvoKing 프리팹에 추가했어. 기존 `LSO_BossPhase.OnPhaseChange`의 2페이즈 알림을 한 번 받아 재생해. `Auto Play Skills`와는 별개로 동작해.

- 시작 시 `Will_CrowKingWing` 자식을 숨김. 비활성 자식까지 이름으로 찾으며 `Wings`에 직접 연결해도 돼.
- 기본 2초 동안 220장의 검은 깃털이 화면 오른쪽 위에서 왼쪽 아래로 흘러가.
- 깃털마다 서로 다른 주기로 옆으로 휘고, 기울어지고, 옆면을 보이듯 폭이 좁아졌다 넓어져. 커스텀 Sprite와 기존 절차적 깃털 모두 같은 휘날림을 사용해.
- `Feather Wind Strength`는 옆으로 휘는 거리(1080 높이 기준 픽셀, 기본 120), `Feather Flutter Speed`는 흔들림 주기 속도(기본 1.5), `Feather Tumble Angle`은 기울어지는 각도(기본 75도), `Feather Flip Amount`는 옆면을 보이는 정도(기본 0.8)야. 플레이 중에도 조절 가능해.
- `Feather Wind Curve`는 X=화면 연출 시간 비율(0~1), Y=휘날림 강도 배율이야. Y=1이면 설정한 강도, Y=0이면 휘날림 없이 직선 이동만 남아. 중간만 높이면 돌풍처럼 강하게 흔들 수 있어. 깃털 이동 속도와 2초 지속 시간, 날개 펼침 타이밍은 별도로 유지돼.
- `Feather Move Speed`는 1080 높이 화면 기준 초당 이동 거리야. 기본 600, 느리게는 300, 빠르게는 1200처럼 설정해. 해상도에 맞춰 비례 조정하며 0이면 직선 이동만 멈춰. 재생 중 바꿔도 위치가 튀지 않아.
- 이전 `Playback Speed` 배율은 제거했어. 깃털 이동 속도를 바꿔도 `Duration`과 화면을 가리는 시점, 날개 활성화 시점은 바뀌지 않아. 화면 밖의 깃털은 순환해 속도가 빨라도 연출 도중 깃털이 모두 소진되지 않아.
- 연출의 48% 지점에 화면이 완전히 가려지면 기존 날개 자식을 아래로 접은 상태로 활성화해. 85% 지점에서 암막이 걷히면 양쪽 날개가 아래에서 위로 올라가며 펼쳐지고, 이후 Burst Delay에 설정한 시간이 지나면 주변 깃털이 한꺼번에 터져. 기본 펼침 시간은 1.2초라 화면 연출이 끝난 뒤에도 이어져.
- `Wing Unfold Duration`은 펼침 시간, `Wing Fold Angle`은 처음 아래로 접는 각도(기본 65도), `Wing Lower Distance`는 추가로 아래에 두는 거리(날개 반폭의 비율, 기본 0.08)야.
- `Wing Unfold Curve` 그래프로 접힌 각도가 풀리는 정도, `Wing Rise Curve` 그래프로 아래에서 올라오는 정도를 각각 편집해. X는 `Wing Unfold Duration`에 대한 시간 비율(0~1), Y는 진행 정도(0=접힌 각도/아래쪽, 1=펼친 각도/원래 높이)야. 기본값은 부드러운 Ease In/Out이고 비어 있는 곡선도 같은 기본 움직임을 사용해.
- 시작 키 (0,0)와 끝 키 (1,1)을 유지하고 중간 키와 기울기를 바꾸면 돼. Y를 1보다 높게 했다가 돌아오게 만들면 더 펼치거나 더 올라간 뒤 정착하는 움직임도 가능해. 종료 시에는 원본 자세로 복구하므로 끝값이 1이 아니면 마지막에 자세가 튈 수 있어. 그래프를 바꾼 뒤 기존 미리보기 버튼으로 다시 재생해.
- `Will_CrowKingWing`은 본 없이 좌우가 한 메시로 합쳐져 있어. `DLJ_CorvoKingWingMotion`이 루트 날개와 자식 Cube/Cylinder의 뾰족한 장식 메시까지 복제해 같은 루트 좌표와 곡선으로 접고 펼쳐. 자식의 위치·회전·스케일 변환을 반영하므로 장식만 제자리에 남지 않아. 원본 메시 파일은 보존하고 끝나거나 비활성화되면 모든 원본 메시를 복구해.
- 런타임에 정점을 읽기 위해 해당 날개 FBX의 Read/Write만 활성화했어. 게임 실행 테스트는 수행하지 않았으므로 실제 화면에서 접는 각도와 펼침 시간을 조절할 수 있어.
- 화면 UI로 그리므로 카메라 깊이나 블룸 설정에 의존하지 않아. `Feather Sprite`가 비어 있으면 기존 깃털 실루엣과 깃결을 단일 UI 메시로 생성해.
- 깃털 연출은 `Game` 뷰에서 확인해. `Scene` 뷰로 날개를 보고 있으면 화면 UI 깃털은 보이지 않아. 화면 깃털은 Duration이 끝나면 사라지고, 날개 펼침은 별도 시간으로 끝까지 진행돼.
- DLJ_TestScene에 Feather Sprite=None, Feather Move Speed=30000 오버라이드가 있어 커스텀 이미지가 빠지고 기본 깃털이 빠르게 이동하는 설정을 확인했어. 해당 씬의 이미지를 Stylized Sprite로 연결하고 이동 속도를 600으로 수정했어. 사용자가 편집한 Duration=3, Feather Count=280과 날개 곡선은 유지했어. Game 뷰에서의 실제 재현 검증은 수행하지 않았어.
- 커스텀 이미지를 쓰려면 투명 배경 PNG를 Unity에 넣고 Texture Type을 `Sprite (2D and UI)`로 변경한 뒤 Apply해. 해당 Sprite를 `Feather Sprite`에 연결하면 다음 재생부터 사용해. 원본 비율과 알파를 유지하며 `Feather Image Tint`는 흰색일 때 원본 색상을 유지해.
- 이미지의 깃털 끝이 위쪽을 향하면 `Feather Image Rotation`은 0으로 사용해. 다른 방향 이미지라면 이 값으로 보정해. 암막은 별도 UI로 유지하므로 이미지의 투명 영역과 관계없이 날개가 바뀌는 순간 화면을 가려.
- `Duration`, `Feather Count`로 길이와 수량을 조절해. Unity 상단 Play를 켜고 활성 CorvoKing의 `DLJ_CorvoKingPhaseTransition` 인스펙터 아래 `2페이즈 깃털 연출 미리보기` 버튼을 누르면 돼. 편집 모드에서는 버튼이 보이지만 비활성 상태야. 컴포넌트 제목 우클릭 메뉴에서도 재생할 수 있어. 미리보기는 전투 페이즈를 바꾸지 않고 날개 표시와 연출만 실행해.
- 게임 시간과 입력은 멈추지 않고 실제 시간으로 재생해. 끝나거나 보스가 비활성화되면 화면 오브젝트를 정리해.

현재 날개 모델은 `DLJ_TestScene`의 CorvoKing에 추가된 자식이야. 다른 씬에서 기본 프리팹을 생성해 사용할 때는 해당 날개 자식도 추가해야 해. 이번 연출의 Unity 실행 테스트는 수행하지 않았어.
