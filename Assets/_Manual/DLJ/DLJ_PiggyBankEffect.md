# DLJ 황금돼지 이펙트

`Assets/_Scenes/DLJ/DLJ_TestScene.unity`의 `Will_Pig`에 `DLJ_PiggyBankEffect`가 연결돼 있어.
기존 `Pig.asset`의 `CostRefund` 특성을 사용해. 다른 기물/턴/사망 스크립트는 수정하지 않았어.

- 자기 턴 시작마다 1개씩 최대 3개까지 저장하는 기존 규칙을 유지해.
- 저장할 때 `Will_CostCoin` 메시 금화가 허공에 나타나 등 구멍으로 내려가고, 도착할 때 몸체의 금빛이 증가해.
- 사망하면 본체를 감추고 금색 파편, 짧은 섬광, 저장한 수만큼의 금화를 생성해. 저장량이 0이어도 폭발은 재생해.
- 금화는 서로 다른 수평 속도와 회전축으로 튀어나와 중력으로 떨어져. 보드 표면에서 반발과 마찰로 감속하고, 짧게 기울어지다가 바닥에 누워 정지해. 대기 중 공중 부유나 반복 회전은 없어.
- 낙하 속도 보정: 사망 금화의 연출 중력은 32, 반발 계수는 0.12~0.2이며 최대 두 번의 접촉 후 0.1초 동안 눕고 정지해. 저금 금화는 0.38초 동안 대기/도착 감속 없이 가속 낙하해.
- 낙하 운동은 연출 전용 계산이라 기물을 물리적으로 밀지 않아. 보드 콜라이더를 찾지 못하는 테스트 배치는 돼지 몸체의 최하단을 바닥으로 사용해. `Scatter Radius`로 흩어지는 정도를 조절할 수 있어.
- 떨어진 금화는 본체와 별도 오브젝트라 본체가 삭제돼도 유지돼. 다음 플레이어 턴의 기본 코스트 리셋과 계약 환급이 끝난 뒤 지급해.
- 6코스트 이상이면 기존 CostSystem이 추가 케이스를 등장시켜. 케이스 등장 완료 후 금화가 빈 슬롯으로 이동하고 도착한 슬롯의 코인을 표시해.
- 합계 10 또는 ActionPointManager의 더 낮은 상한을 넘는 금화는 현장에서 축소 소멸해. 적 행동력에는 지급하지 않아.
- 사망 알림 중복, 비행 중 코스트 소비, 턴 종료, 스테이지 교체 시 남은 표시와 환급을 정리해.
- 실제 행동력은 플레이어 턴에 환급을 시작할 때 증가하고, 코인 도착은 표시 연출이야. 비행 중에도 그 행동력을 사용할 수 있어.
- 플레이어 턴에 죽더라도 기존 환급 규칙과 같이 다음 플레이어 턴에 지급해.

## 조정 / 확인

1. 씬의 `Will_Pig`를 선택하고 `DLJ_PiggyBankEffect`를 확인해.
2. Play 모드의 **금화 저금 미리보기** 버튼으로 실제 저장량을 바꾸지 않고 연출을 확인할 수 있어.
   **사망 연출 바로 보기 / 다시 재생**은 턴이나 저장량을 기다리지 않고 금화 3개로 폭발·낙하를 재생해. 착지 후 잠깐 보여준 다음 본체를 자동 복구해. 다시 누르면 처음부터 재생하고, **사망 미리보기 중지 / 본체 복구**로 즉시 끝낼 수 있어. HP·보드·코스트는 바뀌지 않고 실제 환급도 발생하지 않아. 코스트 케이스로의 회수는 실제 사망 흐름에서 확인해.
3. `Deposit Slot`에 별도 앵커를 연결하면 그 위치를 사용해. 비우면 모델 경계와 `Slot Height Ratio`, `Slot Offset`으로 계산해. Scene 뷰의 노란 기즈모가 도착 위치야.
4. `Glow Per Coin`은 저장당 발광 증가량, `Deposit Duration`은 저금 시간, `Burst Duration`은 폭발 시간, `Collection Duration`은 금화 하나의 회수 시간이야.
5. 사망 환급은 실제 CostRefund 저장량을 사용해. 미리보기 버튼만 누르고 죽이면 미리본 개수가 보상으로 추가되지는 않아.

`DLJ_PigGold.mat`은 몸체와 연출 전용 금색 머티리얼이야. 몸체에는 개체별 복제본을 만들어 발광을 조절하고, 눈의 머티리얼은 유지해.

## 검증 범위

Unity 6000.3.6f1의 컴파일러로 프로젝트 전체 런타임/에디터 스크립트 컴파일을 확인했어.
임시 Unity 프로젝트에서 실제 CostRefund, ActionPointManager, CostSystem, CostCase, 피그 연출 코드를 실행해 21개 검증을 통과했어.
검사 환경에서는 턴/스테이지 이벤트와 케이스 등장 시간 등 외부 의존성만 대역을 사용했어.
저장 상한, 발광 증가, 적 턴 지급 방지, 본체 삭제 후 금화 유지, 중복 지급 방지, 새 케이스 생성, 9/10코스트 상한, 초과 코인 소멸, 스테이지 취소, 비행 중 소비를 포함해.
실제 FBX를 별도로 렌더링해서 등 구멍에 맞춰 위치도 보정했어. 원본 DLJ_TestScene의 전체 전투 플레이와 최종 URP 조명은 아직 직접 확인하지 않았어.

낙하 운동 수정 후에는 별도 Unity 실행 검사로 수평 방출, 서로 다른 회전, 바닥 관통 방지, 2초 이내 착지, 정지 후 위치/회전 유지, 적 턴 지급 방지와 10코스트 상한을 다시 확인했어. 전체 런타임 스크립트 컴파일도 통과했어. 최종 장면에서의 시각 확인은 별도로 필요해.
