# 스테이지 연출 계획

> 기준 문서: 노션 「새로운 UI」
> 담당: 이시온 (LSO)
> 대상: 「여기서부터 다시 스테이지」 ❌ — 보상이 끝난 뒤부터 스테이지가 시작되기까지

---

## 무엇이 남았나

기획서에서 제 담당으로 남은 ❌ 는 둘입니다.

```
「여기서부터 다시 스테이지」(이시온)     ❌   보상 후 → 판 되돌리기 → 기물 배치 → 3갈래
「유언 선택창」(이시온, 김태호)          ❌   도장
```

보상(✅)에도 최근 두 줄이 붙었습니다.

```
카드 3개가 나온다 (클로즈업과 함께)
호버링 할때 인포창이 뜨고
```

이 문서는 첫 번째 항목만 다룹니다.

---

## 기획서가 요구하는 흐름

```
모든 보상 획득
  ↓
체스판이 자동으로 뒤집어진다        (되돌리는 회전)
기물이 자동으로 배치된다
  ↓
세 갈래
```

### 일반 스테이지

기물 배치 후 위의 작은 대화창에 무슨 스테이지인지 표시하고 끝.

### 챕터가 바뀌었을 때

기물 배치 후 화면이 검은색으로 지지직 → 완전 암전 → 챕터에 맞는 스테이지 디자인으로 교체 → 중앙에 지역 이름 (예: 까마귀왕의 둥지)

### 보스 스테이지

기물 배치 후 화면이 완전히 하얗게 덮임 → 가운데 보스 이름 크게 → 위에 이명

## 지금 있는 것 / 없는 것

| 필요한 것 | 상태 | 근거 |
| --- | --- | --- |
| 되돌리는 회전 | **있음** | `LDY_BoardFlipMotion.Rotate` 를 반대로 한 번 더 |
| 기물 자동 배치 | **있음** | `LDY_BoardUnitSpawner.Spawn` · `LDY_StageDirector` 의 스텝 구조 |
| 보상 클로즈업 | **있음** | `LSO_CameraDirector` 에 샷 추가 |
| 일반 스테이지 자막 | **있음** | `KTH_StartMessage.PlayStartMessage()` |
| 하얀 암전 | **없음** | `LSO_ScreenFader` 는 검은 `Image` 전용. 색을 못 정한다 |
| 지지직 암전 | **반쯤** | `LSO_PixelateFullscreen` 셰이더는 있으나 전환 연출로 안 묶여 있다 |
| 지역 이름 데이터 | **없음** | 에디터 창의 `"Chapter 1"` 문자열뿐 |
| 보스 이름·이명 | **없음** | `LSO_AnimalSO` 에 `animalName` 만 있다 |

`LDY_BoardFlipMotion.Restore()` 는 **즉시** 되돌립니다. 연출로 돌리려면 `Rotate` 를 다시 불러야 합니다.

## 단계

### 1단계 — 판 되돌리기 + 기물 배치

세 갈래가 전부 이 위에 얹히므로 제일 먼저 합니다.

```
LSO_RewardBox.OnFinished
  → 판을 반대로 돌린다
  → 기물을 배치한다
  → 갈래를 고른다
```

**결정이 필요합니다.** 되돌리는 회전을 `LDY_BoardFlipDirector` 안에 넣을지, 제 쪽에 `LSO_StageIntroDirector` 를 새로 만들고 `LDY_BoardFlipMotion` 만 빌려 쓸지.

- 안에 넣으면 회전의 주인이 하나로 유지된다. 대신 이도윤 님 파일이 커진다.
- 밖에 두면 제 담당 안에서 끝난다. 대신 같은 보드를 두 곳이 돌리게 된다.

**「자리를 정하는 주체는 하나」** 규칙으로는 안에 넣는 쪽이 맞습니다. 이도윤 님과 얘기가 필요합니다.

### 2단계 — 일반 스테이지

기물 배치 후 자막 한 줄. `KTH_StartMessage` 가 이미 있어서 **연결만 하면 됩니다.**

가장 짧고, 1단계가 제대로 돌아가는지 확인하는 용도로도 좋습니다.

### 3단계 — 보스

```
하얀 덮개 → 보스 이름 → 이명
```

필요한 것 둘.

- `LSO_ScreenFader` 에 색 필드를 추가하거나, 흰색 전용을 하나 더 만든다
- 보스 이름·이명을 담을 데이터 필드

**이름을 어디에 둘지가 결정입니다.**

```
LDY_StageSO 에 넣는다     보스 스테이지에만 채우게 된다. 빈 칸이 대부분
LSO_AnimalSO 에 넣는다    보스 기물에서 읽는다        ← 권장
```

이름은 보스의 성질이지 스테이지의 성질이 아닙니다.

### 4단계 — 챕터 전환

제일 큽니다. **"스테이지 디자인이 바뀐다" 의 범위가 안 정해져 있습니다.**

```
조명만?
배경 오브젝트까지?
타일 머티리얼까지?
```

셋 다면 챕터마다 프리팹 세트가 필요하고, 그건 연출이 아니라 씬 구성 문제입니다.

지역 이름도 담을 데가 없어 `LSO_ChapterSO` 같은 것을 새로 만들어야 합니다.

### 5단계 — 보상 클로즈업

**코드가 필요 없습니다.**

```
LSO_CameraDirector 에 "보상" 샷 추가
LSO_RewardBox.On Dealt      → director.Play("보상")
LSO_RewardBox.On Finished   → director.ReturnToDefault()
```

`Can Return` 은 꺼둡니다. 카드를 고르는 중에 아무 클릭으로 카메라가 빠져나가면 안 됩니다.

---

## 남의 손이 필요한 것

**인포창 호버** — 주다림·김태호 담당(❌). 그쪽이 만들면 카드에 붙이기만 하면 됩니다.

**되돌리는 회전** — 이도윤 님 파일을 건드릴지 결정.

**카드 필드 셋** — 기획서 「카드」 표에 특성 · 기물 점수 · 유언 아이콘이 있는데 `LSO_RewardPieceCard` 에는 없습니다.

```
특성        LSO_CardSO.AbilityTypes 로 읽을 수 있다        → 칸만 추가
유언 아이콘  DLJ_WillDataSO.icon 으로 읽을 수 있다          → 칸만 추가
기물 점수    데이터 자체가 없다                            → 먼저 정의해야 한다
```

## 먼저 정해야 할 것

- [ ] 보스 이름·이명을 어디에 둘지 (`LSO_AnimalSO` 권장)
- [ ] "챕터에 맞는 스테이지 디자인" 의 범위 — 조명만? 배경까지?
- [ ] 지역 이름 (챕터 수만큼) — 누가 쓸지
- [ ] 되돌리는 회전을 `LDY_BoardFlipDirector` 에 넣을지
- [ ] 기물 점수가 무엇인지 — 사망 시 깎이는 양초 체력이면 지금 목숨 시스템과 어떻게 맞물리는지

## 착수 순서

```
1단계 · 2단계    지금 바로 가능
3단계            이름 둘 곳만 정하면 가능
5단계            지금 바로 가능 (코드 없음)
4단계            기획이 더 필요
```

**1단계부터.** 되돌리는 회전과 기물 배치가 되면 나머지는 그 위에 얹는 일입니다.
