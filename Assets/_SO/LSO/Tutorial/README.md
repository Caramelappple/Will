# 튜토리얼 대본

LSO_TestScene의 LSO_TutorialDirector에 5개 챕터 / 51개 Step SO가 연결되어 있습니다.

- 게임 설명 → 전장과 적 → 덱 → 유언 → 체력·보상·스테이지
- 설명은 3.5~6.5초간 표시합니다. 실습 단계는 실제 결과가 확인될 때까지 기다립니다.
- 스페이스를 1초 누르면 기존 기능으로 전체 튜토리얼을 건너뜁니다.

## 실습용 데이터

TutorialBattleChapter는 기존 1막의 첫 전장만 TutorialBattle로 교체한 별도 SO입니다. 테스트 씬의 손패는 TutorialPlayerCard 5장, 적은 TutorialEnemyCard 2장입니다. 원본 기물과 일반 전장의 밸런스 데이터는 유지합니다.

| 행동 | 좌표 (x, z) | 남은 코스트 |
| --- | --- | --- |
| 첫 기물 소환 | (2, 2) | 4 |
| 첫 기물 이동 | (3, 3) | 3 |
| 저주 기물 소환 | (3, 2) | 2 |
| 저주 기물 이동 | (4, 3) | 1 |
| 인접한 적 공격 | (4, 4) 또는 (5, 4) | 0 |

실습용 아군은 체력 2·공격력 1·이동 1·원거리 사거리·소환 코스트 1, 적은 체력 2·공격력 2입니다. 적이 저주 기물을 처치하면 그 자리에 3×3 저주 지역이 2턴 동안 남아, 그 안의 **적만** 매 턴 1씩 피해를 받습니다(아군은 받지 않습니다). 아군 사망당 양초 체력은 5이며, 두 기물이 모두 죽으면 300 → 290이 됩니다. 테스트 씬의 자동 턴 종료를 켜 두었습니다.

촛불에는 저주·분노를 순서대로 넣어 숫자 1이 저주를 선택합니다. TutorialRewards는 첫 전투에서 새 계승 유언을 얻을 수 있도록 설정했습니다. 실제 보상 시스템에 맞춰 상자 열기 → 한 번 더 눌러 카드 꺼내기 → 동료 선택 → 유언 메모장 확인 순서로 안내합니다.

## 편집과 확인

안내문·카메라 이름·허용 조작은 각 Step SO에서, 완료 조건은 Gates의 SO에서 수정합니다. 배치/이동 좌표를 바꾸면 Step의 guideTiles와 Gate의 tile을 함께 수정해야 합니다. 유언 배치의 PlaceYellow는 노란 표시와 배치 제한을 함께 적용합니다.

프로젝트 루트에서 `node Tools/validate-tutorial.cjs`로 챕터·샷·관문 참조 및 실습 좌표를 확인할 수 있습니다. C# 빌드는 통과했으며 실제 Play Mode의 카메라 구도·클릭 판정·보상 연출은 별도로 확인해야 합니다.
